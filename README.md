# Dedicated Damini — GitHub Pages site

This is a static, responsive website for Dedicated Damini.

## Files
- `index.html` — homepage
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/` — supplied images

## Publish on GitHub Pages
1. Create/open the GitHub repository you want to use.
2. Upload all files in this folder, preserving the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and the `/ (root)` folder, then save.
6. GitHub will provide the Pages URL.
